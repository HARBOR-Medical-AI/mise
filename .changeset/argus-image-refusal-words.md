An image that fails to load says why in plain words, never as the porter's JSON. It reads `THE SESSION CLOSED THE CONNECTION BEFORE IT ANSWERED (OTHER SIDE CLOSED)`, `THE FILE DID NOT ARRIVE FROM CUBE: <CAUSE>`, or, for a file whose body broke off, `THE FILE STOPPED ARRIVING PART WAY (1.2 MB OF 3.0 MB)`. `COULD NOT BE DECODED` is said only for a file that came whole.
