A machine's SIZE seat now builds too: DECLARE saves the size, BUILD applies it, and an unbuilt size says so.

On the VM controller and the script screen, a `vm new` or `net new` line holds the build line right after it of the same name as one seat. The seat shows both lines and two pills: DECLARE (the declaration alone, which builds nothing) and BUILD in the billing tone (the declaration as shown, then the build, whose plan, cost and question still come first; the password is asked before either line when the session must be raised; a refused declaration builds nothing). The separate BUILD seat is gone wherever the build follows its declaration. A size declared and not built wears DECLARED · NOT BUILT at the top of COST · AS SIZED with what a build would change (`disk 50 → 180`) and that BUILD applies it. The price beside the sliders follows them within a tenth of a second, a late answer to an older move never overwrites a newer one, and the column names when the session read the price list. On the VM controller a slider's edit is written to the script before the line it changed is sent, so what was declared reads done.
