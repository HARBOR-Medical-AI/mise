A file name that arrives from the other side cannot leave its folder. A name delivered to a shell, or listed by ChRIS for a berth's anchor, is placed inside the folder it belongs in or refused by name: never absolute, never climbing out with `..`, never through a link that leads elsewhere. A shell attached to a session elsewhere writes a delivered file only where the `download` line it sent said to; a delivery to any other place, or after the line ended, is refused. A destination written as a variable is not known to the shell that typed it and is refused under a remote session: type the path. A refresh of an anchor whose listing holds a name that cannot be placed keeps the anchor that stands.
