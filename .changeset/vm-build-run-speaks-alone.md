A machine's build speaks alone once pressed, from its first second, and asks its question in plain words. While a build runs the offer above BUILD is gone, and it returns afterwards only if something is still to build. The run box appears the instant the build is confirmed with PREPARE under way (writing the declaration, keeping it, readying the stacks), and carries no hint lines. The question reads as the act ("Resize store's boot disk 100 → 150 GB? Grown online, no reboot. $39.95 → $42.08 a month.") with buttons that say what each answer does: YES · RESIZE and NO · BUILD NOTHING.
