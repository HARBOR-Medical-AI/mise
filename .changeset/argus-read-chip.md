The stratus takeovers wear the door's answer, READ or MANAGE, and in READ hold every control that would act, saying why.

A chip in the header reads READ · NOTHING OUTSIDE THIS HOST CHANGES or MANAGE; BUILD, ADOPT, TEAR DOWN, RUN on a build or a deploy, TEARDOWN and ADD read REFUSED with the door as their reason, so a press in READ never looks like a request to escalate (docs/stratus.adoc, D14).
