A token is printed only to a terminal, a saved token is its owner's alone, and the shell's history holds no secret. A daemon whose output is not a terminal (a log, a journal) names the berth record that keeps its token, not the token. The saved CUBE token is written at 0600 in a 0700 folder, and one saved looser before is tightened when next read. The shell's history moves from `.chell_history` in whatever folder the shell was started in to `$XDG_STATE_HOME/chell/history` (else `~/.local/state/chell/history`), private from its first line; an old `.chell_history` in a checkout is left as it is and no longer read. A line is kept with the value of `--password`, `--adminPassword`, `--token`, `--auth-token`, `-p` on `connect`, a password inside an address and a `token=` replaced by `***`; a password typed at a hidden question is never recalled by the up arrow.
